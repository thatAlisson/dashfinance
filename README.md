# 💰 DashFinance - Gerenciador Financeiro Pessoal

Aplicação web interativa para gestão de receitas e despesas pessoais desenvolvida com JavaScript Vanilla, HTML5 e CSS3.

## 🚀 Funcionalidades

- ➕ Adição de entradas e saídas financeiras.
- 📊 Cálculo dinâmico de saldo total, total de entradas e saídas.
- 💾 Persistência de dados local via `localStorage`.
- 🗑️ Exclusão de transações.
- 💲 Formatação automática de valores para Real (BRL).

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estruturação semântica.
- **CSS3**: Estilização responsiva e moderna.
- **JavaScript ES6+**: Manipulação de DOM, Array Methods (`reduce`, `filter`), `localStorage` e Web APIs (`Intl.NumberFormat`).
